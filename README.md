# Project Babylon

Project Babylon is a first-person stationary space-defense game built with Babylon.js.

The player controls two cannons and must destroy 20 UFOs while managing health and energy. An internal 0.5s firing cooldown was implemented to prevent the player from spamming or accidentally double clicking. The player fails on the fifth shot that they receive. The game includes enemy AI, laser combat, sound effects, background music, visual effects, an overhead UFO mothership, win/lose states, and a restart system.

## Controls

- Left Mouse Button: Fire left cannon
- Right Mouse Button: Fire right cannon
- Mouse: Aim
- Space: Start game
- R: Restart after win or loss
